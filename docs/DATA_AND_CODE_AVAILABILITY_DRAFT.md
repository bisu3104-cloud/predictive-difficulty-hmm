# Data and Code Availability — draft

The selected HMM parameters, run-level neural and count-predictor results, cohort-selection records, frozen prediction outputs, and scripts required to reproduce the reported analyses will be released in a public GitHub repository and archived on Zenodo. The archive includes transition matrices, emission matrices, stationary distributions, deterministic generation metadata, and selection locks for the development, confirmatory, predictor-specific, strict-replication, external-generator, and dataset-realization robustness analyses. It also includes the run-level and aggregate CSV files used for the tables and figures.

For the dataset-realization robustness experiment, the archive includes the outcome-blind 16-HMM selection, public protocol, all 1,152 run-level results, split seeds, dataset checksums, and scripts that reconstruct the reported rank-stability, ICC, PCA, and frozen-prediction results. The regenerated sequence arrays and large neural checkpoints are not included because they are not required for reproducing the statistical analyses; dataset replicates 1 and 2 can be regenerated from the included HMM parameters and recorded seeds. The original replicate-0 sequence cache was unavailable, but its completed run summaries are included.

The archive also includes standalone reconstructions of the nested leave-one-HMM-out composite analysis, external PLS transfer, seed-aware variance-component analysis, and dataset-realization robustness analysis. A permanent DOI and repository URL will be inserted after release.
