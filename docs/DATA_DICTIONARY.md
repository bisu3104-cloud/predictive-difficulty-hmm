# Data dictionary

A machine-readable column inventory is provided in `SCHEMA.csv`. Core definitions follow the manuscript:

- `shape_rmse`: anchored context-response Shape RMSE, using the difference from the model and Bayes values at context length `H=4`.
- `excess_ce_H`: model test cross-entropy at `H=4` minus the exact Bayes cross-entropy.
- `A_width_shape`: Shape RMSE averaged over the fixed representation-width grid for a cohort.
- `context_gain_area`: sum of the Bayes cross-entropy reductions relative to `H=4`.
- `pred_h4_m*_r95`: number of singular components required for 95% of squared spectral energy.
- `pred_h4_m*_sigma95`: singular value at the 95% energy boundary.
- `pred_h4_m*_effective_rank`: entropy-based effective rank using squared singular-value energy.
- `tau_observed_proxy`: finite-lag observed-dependence mixing proxy.

The full column-by-file listing is intentionally exhaustive; columns marked as awaiting a finalized description will be documented during the final analysis-script consolidation.

## Seed-aware variance-component outputs

Files under `outputs/variance_components/` are generated by
`code/scripts/reconstruct_seed_aware_variance.py`.

- `interaction_share`: truncated method-of-moments interaction variance divided by the sum of truncated process and interaction variances.
- `ordinary_cluster_ci_*`: percentile interval from resampling 64 HMMs as clusters while retaining all eight conditions and five seeds.
- `k_stratified_ci_*`: sensitivity interval from resampling 16 HMMs within each value of \(K\).
- `process_variance_raw` and `interaction_variance_raw`: unconstrained method-of-moments estimates.
- `process_variance` and `interaction_variance`: estimates truncated at zero when computing the interaction share.
- `full_cohort_mean` and `full_cohort_population_sd`: fixed condition-wise scaling values used before point estimation and bootstrap resampling.

## Dataset-realization robustness files

Files prefixed `dataset_realization__` support manuscript Section 5.4 and Appendix H.

- `dataset_replicate`: dataset realization identifier; 0 is the original confirmatory split and 1–2 are independently regenerated train/validation/test splits.
- `condition_seed`: deterministic training-window/randomness seed used by a newly trained architecture–width–seed condition.
- `dataset_replicate_manifest.csv`: split seeds and SHA-256 checksums for regenerated datasets. The sequence arrays are intentionally not archived.
- `A_width_shape`: HMM-level Shape RMSE averaged over widths 8, 32, 128, and 256 after averaging over training seeds 1–3.
- `process_icc`: one-way process intraclass correlation across the three dataset realizations, computed as truncated process variance divided by process plus within-process dataset variance.
- `dataset_pair_spearman_*`: stability of HMM-level difficulty ordering between pairs of dataset realizations.
- `pc1_loading`: loading of a condition on the first principal component of the condition-standardized 16-by-8 Shape matrix; component signs are oriented to have positive mean loading.
- `augmented_rmse_reduction_percent`: percentage RMSE reduction of the frozen development-fitted augmented profile relative to the frozen K-only predictor.
- `regenerated://`: provenance marker for a dataset that is reproducible from HMM parameters and recorded seeds but not stored in the archive.
