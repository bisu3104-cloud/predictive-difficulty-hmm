# Excluded experimental archives

The following archives are intentionally excluded from the main public artifact:

- `predictive_profile_experiment_v1.zip`: incomplete predecessor with a different selected cohort.
- `saturation_experiment...zip`: old stationary-distribution inconsistency; not used in the current manuscript.
- `samek_diagnostic_experiment...zip`: early diagnostic experiment using a different Shape metric.
- `bootstrap_regenerated...zip`: mean-centered Shape metric, not the anchored metric in the manuscript.
- duplicated strict-replication ZIP copy.
- K-sensitivity archives: valid auxiliary experiments, but not part of the current manuscript's principal cohort structure.

These exclusions prevent obsolete or definition-incompatible results from being mixed with the final evidence base.
